# BackendCodegen.Cli

Scriban-based backend boilerplate generator.

## Generate files

```bash
dotnet run --project tools/BackendCodegen.Cli -- generate --contract <contractPath> --templates tools/BackendCodegen.Cli/Templates
```

## Run codegen tests

```bash
dotnet test tools/BackendCodegen.Cli.Tests/BackendCodegen.Cli.Tests.csproj
```

## Manual pre-orchestrator validation (recommended)

Use these checks manually before starting orchestrator runs **only when generator/templates changed**:

```powershell
powershell -ExecutionPolicy Bypass -File tools/BackendCodegen.Cli.Tests/run-preflight.ps1
```

```bash
bash tools/BackendCodegen.Cli.Tests/run-preflight.sh
```

These checks are intentionally developer-triggered and are not required to be added to pipeline or orchestrator flow.

## DATA slice generation

The generator supports DATA slices (entity + EF configuration scaffolding). Set these flags in the contract:

```json
"generation": {
  "generateEntity": true,
  "generateEntityConfiguration": true
}
```

Requires a `dataModel` section in the contract:

```json
"dataModel": {
  "tableName": "MyTable",
  "schema": null,
  "primaryKey": "Id",
  "indexes": [
    { "fields": ["Status"], "isUnique": false }
  ]
}
```

`dataModel.recordLock` is **required** for DATA generation (US 11038, see `.github/skills/record-locking/SKILL.md`). Pick one:

```json
"recordLock": { "kind": "record" }
"recordLock": { "kind": "partOf", "parent": "Client", "fk": "ClientId" }
"recordLock": { "kind": "partOf", "parent": "Client", "fk": "ClientId", "ownerlessIs": "notLockable" }
"recordLock": { "kind": "notLockable", "reason": "settings: widget catalog" }
```

- `record` emits `builder.IsLockableRecord();` plus a `Version` rowversion property and `IsRowVersion()` mapping.
- `partOf` emits `builder.IsPartOfRecord<{EntityName}, {parent}>(x => x.{fk});` (with `OwnerlessIs.NotLockable` when set).
- `notLockable` emits `builder.IsNotLockable("{reason}");`.
- A missing or incomplete `recordLock` fails validation before any file is written.
- Generated controllers never carry `[SkipRecordLock]`.

Generated files:
- `{domainRoot}/{EntityName}.cs` — entity class with EF private constructor
- `{infrastructureRoot}/Persistence/Configurations/{EntityName}Configuration.cs` — Fluent API configuration

**Migrations are NOT generated by this tool.** Run EF CLI after generation:

```bash
dotnet ef migrations add YYYYMMDDHHMMSS_DescriptiveName \
  --context {DbContext} \
  --project {DataProject} \
  --output-dir {MigrationsFolder}
```

## Notes

- The generator runs with `StrictVariables = true` for Scriban templates.
- Missing templates or render errors fail generation (fail-fast).
- Collection response DTO inputs like `FooResponse[]` are normalized to `IReadOnlyList<FooResponse>`.
- DATA generation flags require `dataModel` to be non-null — the generator fails early otherwise.
- DATA generation also requires `dataModel.recordLock` (see above).
